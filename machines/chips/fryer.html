Temperature Control

Honeywell UDC3200 Controller

Manufacturer Honeywell
Controller UDC3200 Universal Digital Controller
Controller Type Microprocessor-based stand-alone process controller
Typical Application Temperature and process-variable control in heating, cooling, ovens, packaging, and food-processing applications
Analog Inputs Two universal analog inputs
Typical Input Accuracy ±0.20% of full scale
Input Sampling Six samples per second (166 ms)
Supported Input Types Thermocouple, RTD, Radiamatic, millivolt, voltage, and current configurations depending on setup
Outputs Supports relay, solid-state relay, open collector, and current output configurations depending on installed options
Communications Modbus RTU / RS-422/485 and Ethernet TCP/IP options; infrared configuration interface
Front Protection NEMA 4X / IP66 when properly panel mounted
Standard Power 90–264 VAC, 50/60 Hz; optional 24 VAC/DC instrument power

Controller Functions

UDC3200 Reference

Configuration Tuning, setpoint ramp, Accutune, algorithms, outputs, inputs, communications, alarms, and display settings
Operation Process monitoring, manual/automatic control, setpoints, alarms, timer, tuning, failsafe, and ramp/soak programming
Calibration Input and output calibration procedures are included in the fryer manual library
Troubleshooting Power-up tests, status tests, background tests, controller failure symptoms, communications troubleshooting, and factory configuration restoration
Service Parts Exploded view and controller parts identification are included in the Honeywell manual

# Siete Document Portal

Maintenance manuals, SOPs, and machine documentation for Siete Family Foods.

## Website and installable app

Live portal: https://malamal32.github.io/SieteMaintenanceV2/

The website is an installable Progressive Web App (PWA). In a supported browser, open the portal and select **Install App**. The installed app continues to use GitHub Pages, so updates pushed to `main` appear automatically.

## Windows download

Open the repository's **Releases** page and download the latest `Siete-Document-Portal-Setup-1.0.0.exe` file:

https://github.com/Malamal32/SieteMaintenanceV2/releases/latest

The Windows app is a lightweight wrapper around the live portal. Document updates do not require users to reinstall it.

## Updating the portal

Continue editing and uploading site files through GitHub as usual. GitHub Pages publishes the changes, and both installed versions receive the current content on their next online load.

A new Windows installer is built automatically only when the desktop wrapper, logo, or Windows build workflow changes.
